# Računarski vid (Computer Vision)

Ovaj repozitorijum sadrži laboratorijske vežbe iz predmeta **Računarski vid**.

Svaka laboratorijska vežba organizovana je u zasebnom direktorijumu koji sadrži implementaciju, izvorni kod i potrebne resurse.

## Korišćene tehnologije

- Python
- NumPy
- OpenCV
- Matplotlib

## Cilj repozitorijuma

Cilj repozitorijuma je praktično upoznavanje sa osnovnim konceptima, metodama i tehnikama računarskog vida i obrade digitalnih slika.
